The question

Does the communication network between bone-marrow cells — not just the blast count — carry information about AML?

Three pre-registered predictions we set out to test (and could be proven wrong):

H1 · Convergence

A shared LSC→niche signal

The same leukemic-stem-cell → microenvironment signals recur in most independent studies and across genetic, epigenetic, and cell-state groupings.

H2 · Topology

The wiring, not one pair

The shape of the network separates AML from healthy better than any single ligand-receptor pair, or than simply counting cell types.

H3 · Trajectory

How it changes with treatment

From diagnosis → residual disease → relapse, the network follows one of three possible patterns — steady rise, dip-and-rebound, or a turn in a new direction.

Design

From 13 datasets to a fair comparison of niche networks

  • 13 public AML + healthy bone-marrow datasets → label which cells are cancerous
  • Place every cell on a fixed 7-type map of blood-cell development (stem/progenitor → mature)
  • Build one communication network per patient, then compare their shapes with optimal transport
  • Samples drop off at each step; the strictest test rests on 60 samples from 3 datasets
Status

The machine is built — and it is built to try to disprove itself

  • Running end-to-end: 148 patient communication networks, aligned and compared, with the safeguards most papers skip — shuffle-based significance tests, a control for sequencing platform, and a breakdown of which feature carries any signal.
  • One step is clean today — placing cells on the developmental map: full coverage, and the cancer labels are kept completely separate from where a cell sits on the map.
  • One caveat to say up front: the communication step so far uses only one tool (CellChat). The plan calls for a second (LIANA+), so every network result — including H1 — is still preliminary until we repeat it.
  • These results are the first-pass pipeline; the design was updated two days ago (v1.1) and already anticipates most of what we see here.
What the networks contain

Who signals to whom, and with which molecules

  • Before asking what is different in AML, here is what the networks actually contain.
  • Who talks (left): the immature stem/progenitor cells and the monocytes/dendritic cells are the busiest senders and receivers.
  • Which molecules (right): a few pairs dominate — MIF and Galectin-9 lead, both known immune-dampening signals in AML, alongside CD99 and PECAM1.
  • On the stem→immune route specifically, MIF and Galectin-9 are again the leads — a plausible immune-evasion channel, and exactly what H1 tests next.
H1 · Convergence

No communication link is reliably different in AML — a clean "no"

  • 0 of 49 sender→receiver links stand out from chance; grouped into 5 families, all sit far from significance.
  • The stem→immune route (our main hypothesis) leans slightly stronger in AML, but not significantly (p=0.86).
  • Why we trust this one: it never uses the cancer-cell labels — so the labelling problem on the next slide cannot distort it.
  • Caveat: so far this is CellChat only. We still need to repeat it with LIANA+/NicheNet before calling it final.
The weak spot

The weak spot is deciding which cells are cancerous

  • The plan was three methods agreeing; in practice 125 of 130 samples rest on just one (inferCNV).
  • Tested on healthy marrow (where any "cancer" call is wrong by definition): the stem-cell type — the one our hypothesis needs most — is mislabelled ~40% of the time.
  • Immune cells are clean (3–8%); stem and myeloid cells are not — a known blind spot of the method, not real disease.
  • Stroma is 90% wrong — which is exactly why we exclude it from the networks. It never enters the analysis.
H2 · Topology

Today the signal comes from cell counts, not network shape

  • When we rely on the network shape alone (left panel, right-hand edge), the signal disappears — not significant.
  • All of it comes from the cell features, and mostly from the blast-fraction feature — which we hard-set to 0 in healthy samples, so it just re-states "AML vs healthy." Stemness, the feature we care about, does nothing.
  • So shape adds nothing yet. The fair test needs the planned upgrades (honest, richer features; a "direction" score) — not yet built.
H3 · Trajectory

The dip-and-rebound is expected — but we can't judge it yet

  • Stemness dips at residual disease and rebounds at relapse — a V-shape.
  • This is not a failure: the updated plan pre-registered this V as one of three allowed patterns, and it is the one expected at residual disease.
  • But we can't judge it: the scores that tell the three patterns apart aren't built yet, one patient contributes 62% of the residual-disease cells, and the timepoint labels still need checking against the papers.
The fix

Fix the labels first, then run the richer tests

  • Add a second labelling method (CopyKAT / SCEVAN) that runs on every sample with no extra sequencing, and decides "which cells are normal" differently from the first — so agreement removes method-specific mistakes.
  • Measure the gain, don't assume it: re-run the healthy-marrow check on the new method — if the stem-cell error stays near 40%, both methods share the same blind spot and we need a different fix.
  • Honest limits: both read gene activity, so they can miss the same things; and mutation-only leukemias (e.g. NPM1) need a DNA-based method we haven't switched on yet.
  • Then: re-run only the downstream steps (the communication networks don't need rebuilding), and add the planned upgrades that finally make the real network and trajectory tests possible.
