AML Niche-Topology Pipeline

Phase 1 — Progress
& Stress-Test

The pipeline is preliminarily built end-to-end, and we ran the falsification tests most groups skip. They gave us one label-independent null (H1) and localized a fixable problem in the malignant-labelling layer — before any niche claim went out. The fix is scoped.

2026-07-24/ Phase-1 foundation assessment/ read against blueprint v1.0 + v1.1
The question

Does the communication network — not the blast count — carry AML disease information?

Three pre-registered, falsifiable hypotheses (as of blueprint v1.1):

H1 · Convergence

A conserved LSC→niche axis

A set of LSC-like → microenvironment axes reproduces in ≥60% of studies, enriched across three orthogonal strata: genetic, epigenetic (ATAC), transcriptional state.

H2 · Topology

Structure > any single pair

Network topology (with its direction of deviation) discriminates AML vs healthy better than the best single L–R, a composition-only, and a node-feature-only model.

H3 · Trajectory

How it moves under treatment

Dx → MRD → Relapse as a competition of three models — monotone / V-rebound / hysteresis — not assumed monotone.

Design

From 13 datasets to an optimal-transport comparison of niche graphs

  • 13 public AML + healthy marrow scRNA-seq datasets → consensus malignant labels
  • Projection onto a frozen 7-node hematopoietic-immune niche (HSC_MPP, LMPP_GMP, Mono_DC, Erythroid, Megakaryocyte, T_NK, B_Plasma)
  • Per-sample cell–cell communication graphs → Fused Gromov-Wasserstein alignment → permutation tests
  • The platform-controlled test ultimately rests on 3 datasets / 60 samples — not a nested funnel
Status

Preliminarily built — and deliberately self-critical

  • Running end-to-end (first pass): 148 CellChat graphs, FGW barycenter alignment, and an adversarial test layer — per-edge/block permutation nulls, a pre-registered α-sweep, a platform control, feature decomposition.
  • Phase 2 (hierarchy projection) passes clean: 220/220 coverage, malignant identity kept orthogonal to the projection, 7-node vocabulary frozen.
  • Caveat — single method: the communication layer is CellChat only so far; the blueprint's primary engine is LIANA+ (plus a two-method gate and NicheNet). An implementation gap, not a design gap.
  • These results are the un-amended v1.0 pipeline; the v1.1 patch (two days ago) already scopes the fixes for most of what they show.
H1 · Convergence

The network null is clean — and it never touches the labels

  • 0 of 49 directed edges pass permutation (best: HSC_MPP→T_NK, p=0.052); all 5 blocks q=0.93.
  • The primary SCS axis (LSC → immune) is nominally stronger in AML but p=0.86 — a hint in the predicted direction, drowned in noise.
  • Why it matters: H1's edges come straight from CellChat and never pass through the malignant labels — so this null is immune to the label problem on the next slide.
  • Two honest limits: CellChat-only, and v1.1's triple stratification not yet run.
The foundation

The label layer is the crack: the LSC bin is ~40% false positives

  • 125 / 130 samples are single-arm inferCNV; 0 reach the specified 3-way consensus.
  • Healthy-marrow control: HSC_MPP ≈ 40% false-positive — the exact node the LSC hypothesis leans on, and the dirtiest in the graph.
  • Lymphoid clean (T_NK 3.6%), primitive/myeloid dirty — the signature of a method artifact, not rare clones.
  • Stroma's 90% FP is why stroma is excluded — a diagnostic, never shipped into the graph.
H2 · Topology

The signal is composition, not topology — on the pre-registered control arm

  • At pure topology (α=1) the effect is null (p=0.11); the discrimination lives entirely at the feature end (α=0: p=0.0009).
  • v1.1 makes that α=0 endpoint H2's formal control arm (c) — so topology currently adds no increment over features.
  • But the winner is the circular frac_malignant (forced to 0 in healthy); and stemness — the intended biology — is null (β=−0.015).
  • Not yet the decisive test: M8 honest features + M6 direction (cosθ, HDS⊥) are not built.
H3 · Trajectory

The V-shape is a pre-registered model, not a failure — but the test is un-run

  • Stemness dips at MRD, rebounds at Relapse — a V-shape. Under v1.1's M6 this is the pre-registered Model B (rebound), not a broken monotone prediction.
  • The A/B/C competition can't be run yet: it needs the M6 direction scores (HDS∥, HDS⊥, cosθ) — placeholder scripts only.
  • And it's patient-confounded: 62% of MRD malignant cells come from one sample (6323_MRD); metadata unverified.
  • Net: H3 blocked on the M6 machinery + metadata — not on the shape of the trend.
The fix

Harden the label layer first, then implement v1.1

  • Second, cohort-wide evidence arm — CopyKAT / SCEVAN (read the QC object directly, no BAM). They define "who is normal" differently from inferCNV, so agreement cuts method-specific false positives.
  • Measure, don't assert: re-run the healthy-marrow FPR control on them — if HSC_MPP stays ~40%, the confounder is biological and consensus won't fix it.
  • Honest limits: same modality (not orthogonal like Numbat/VarTrix); copy-neutral clones (NPM1) stay invisible — that's the SNV arm's job, currently a stub.
  • Sequence: reconcile metadata → add the arm → re-run Phase 6–8 only (CellChat needn't re-run — edges are label-independent) → then the v1.1 backlog: M8 features & M6 direction (these unlock the real H2/H3 tests) → LIANA+/NicheNet gate → Phase 8 robustness.
