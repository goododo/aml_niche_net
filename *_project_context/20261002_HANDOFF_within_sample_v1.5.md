## 0. 一页摘要

**要回答的问题**，按四个原始设想排：

- 设想 C：同一状态的白血病细胞里，是不是少数细胞在提供信号、多数细胞受益。
- 设想 A：扣掉细胞比例之后，有没有多类细胞一起变的程序，治疗之后它是否仍然异常。
- 设想 B：这个治疗后仍在的程序，是不是由蛋白信号和代谢物信号共同维持，两者可以互相替代。
- 设想 D：搁置，只留作验证。

**做法上的共同点**：旧主线有两步容易出问题。一是按细胞类型汇总配受体打分，容易被细胞比例带着走。二是拿不同样本互相比，容易被平台差异带着走。所以现在把比较放到同一个样本内部，证据改看“接收细胞有没有真的起反应”。

**工作包**

| 工作包 | 对应设想 | 一句话 | 现状 |
|---|---|---|---|
| WP1 样本内部的分工 | C | 同一分箱内，谁是提供者，谁是受益者 | 进行中。全部区室的组合数已过门槛；同分箱的组合数还没数（T3d） |
| WP2 治疗后仍在的多细胞程序 | A | 扣掉比例后的多细胞程序，缓解期是否仍异常 | 与 WP1 并行，可以开工 |
| WP3 代偿与共享瓶颈 | B | 蛋白信号和代谢物信号能否互相替代，共同维持 WP2 的程序 | 等 WP2 |
| WP4 验证模块 | D 的保留部分 | 外部单细胞、bulk 队列、公开扰动数据、后续实验 | 未开始 |
| 模块 G 基因型注释 | 不属于四个设想 | 用 NPM1 读数标注细胞群的突变细胞比例 | 暂停投入 |

**下一步**：两条线并行。线一是 §16 的 T3a–T3d；线二是 W2a–W2c。

## 1. 已定的前提（本轮对话确认）

1. 目标是一条能出正向结果的新主线，可以替换旧主线，数据可以重选。
2. 核心分析只用 scRNA-seq 或 snRNA-seq，加样本临床元数据。不用空间转录组、单细胞表观多组学、自建 CRISPR 实验。
3. 不讲“分化停滞”，不讲“某两类细胞通讯异常”这类结论。
4. 计算分析是主体。实验只做验证，可做的类型：细胞系敲基因或加药、细胞因子或阻断抗体、共培养、特定突变的小鼠模型。
5. 公开 bulk 队列（TCGA-LAML、BeatAML）可以用于验证。
6. 突变类型不设限，按公开数据量来定。
7. 排序标准：成功率第一，其次看能拿到的数据数量和质量。
8. 文章卖点不预设，方法或发现都可以，哪个容易成做哪个。
9. 配受体通讯放在“解释原因”的位置，除非某个做法能证明自己不受细胞比例影响。
10. 有 GPU，随时可用。
11. NPM1 基因型这一层不在主线上，降为可选模块（2026-10-02 定）。
12. doublet 用两种口径并行：并集剔除；不硬剔除、分数作协变量（2026-10-02 定）。
13. 第一阶段用线性模型，不装 MAST（2026-10-02 定）。
14. ≥10 位患者的研究做发现，≥8 位的做重复（2026-10-02 定）。
15. 环境 RNA 用数据内估计，不依赖未过滤矩阵（2026-10-02 定）。
16. 可行性试验的代码放在单独的 `scripts/ws/`（2026-10-02 定）。
17. 接收细胞用分箱内全部通过投影质控的细胞，不只取恶性细胞（2026-10-02 定）。
18. 重心是资料里的四个设想。WP1 的主分析是设想 C（同分箱内的分工）；跨区室的组合只作对照和背景（2026-10-02 定）。
19. WP2（设想 A）与 WP1 并行（2026-10-02 定）。
20. WP3（设想 B）的对象固定为 WP2 的“缓解期仍异常的程序”，保留代谢物一侧的输入（2026-10-02 定）。
21. 设想 D 作为独立设想搁置；模块 G 暂停投入（2026-10-02 定）。

## 2. 前情：旧主线留下的教训

以下是项目已有结论，细节以项目内的 findings 文档为准。

- 按细胞类型汇总的 CCC 距离、OT 距离，没有一种超过“7 类细胞比例”（`prop7`）这个基线。
- AML 与健康骨髓在网络拓扑上分不开，这不是样本量的问题。
- 同一患者前后的变化是真实的，但变化方向在患者之间不一致，所以“诊断 → MRD → 复发单调加深”这类检验做不成。
- 平台效应会明显污染跨数据集的梯度。
- inferCNV 会漏判静息的白血病干细胞，MRD 期的恶性细胞判定不可靠。
- 骨髓穿刺样本里基本没有基质细胞，“niche”实际指造血和免疫细胞。
- 分选或 MACS 富集样本的细胞比例反映的是操作，不能当作真实丰度。
- 现有的纵向配对是 11 对，都是诊断 → 复发：9 对来自 GSE227903，2 对来自 GSE201966。

## 3. 设计原则

- **P1 比较在样本内部完成**，或在同一患者的前后之间完成。跨样本的比较只出现在第二阶段，并且以患者为单位。
- **P2 通讯的证据看接收细胞的反应**。配体和受体都表达不算证据。
- **P3 统计单位是患者**。细胞数不能增加独立样本量，细胞层面的重采样只用来估计测量稳定性。
- **P4 每个结论先过三个对照**：细胞比例基线（`prop7`）、表达水平匹配的随机基因集、打乱配受体配对的假配对。
- **P5 先做小检验，再投入**。每个 WP 有通过门槛，不通过就换做法或停。
- **P6 程序先在单个研究内部发现，再跨研究重复**。不把不同平台的样本混在一起找规律。

## 5. WP1 样本内部的分工（设想 C）

只用 count 矩阵和已有的细胞注释，不需要原始 reads。

### 5.1 假设

- **H-C1 少数提供者**：同一层级状态的白血病细胞里，少数细胞贡献了某些配体的大部分表达。这种不均匀超过随机期望，在多位患者里重复出现，并且不能被更细的状态、细胞周期或测序深度解释。
- **H-C2 多数受益者**：同一状态里不表达该配体、但带对应受体的细胞，出现可测的表达变化。提供者越多的患者，这种变化越强。
- **H-C3 受益的内容**：这种变化包含增殖或存活相关的程序。

跨区室的组合（例如 T/NK 细胞发信号、白血病细胞收信号）不是本工作包的主结果。它们用同一套检验跑，作用是阳性对照和背景，放在补充材料里。这类结果单独拿出来，就是“某类免疫细胞和肿瘤细胞通讯异常”，不是要讲的故事。

### 5.3 预处理

**1. doublet：一条臂 + 一个敏感性分析（2026-10-05 修订，依据见下）**

| 项 | 做法 |
|---|---|
| 主口径（唯一的分析臂） | 细胞全部保留；**scDblFinder 的连续分数**放进第一阶段模型作协变量 |
| 敏感性分析 | 并集硬剔除，只对最终要报告的组合跑一遍 |
| H-C1 的 provider 检查 | **保留两个 caller**，因为那里「两者给出同一个答案」本身就是证据 |

**为什么从「两 caller × 两口径、都要成立」简化成这样**（T3a 实测，88 文库 / 267,157 细胞）：

- **按文库跑之后，原来那个「过切 1.73 倍」基本消失**（中位 0.70×）。28 样本校准的警报很大一部分是把混样文库按样本算预期率造成的：GSE185381 的 20 个混样文库 demux 后同供者比例中位 0.428，按样本算预期率会把目标抬高约一倍。预期率用 `n_raw × 8e-6`（过 QC 之前的计数，已精确核对）。
- **两个 caller 在逐细胞层面几乎不重叠**：Jaccard 0.05；scDblFinder 标 3.28%、DoubletFinder 标 4.34%、两者都标仅 0.91%。所以它们的交集不是共识，是 0.9%，不能当作「更严的口径」。
- **但它们在群体层面一致**：配体阳性的「少数提供者」细胞 doublet 富集 RR 1.28–1.57（scDblFinder）和 1.43–1.53（DoubletFinder），两个分箱、二项检验 p 低至 1e-324。连续分数同向，不是阈值效应。
- **富集显著但量级极小**：Mono_DC 的 592,846 个提供者观测里超出背景的只有 4,903 个，**占提供者集合 0.83%**。所以硬剔除改变不了任何结论，而它会改变接收细胞集合的构成——那是本设计最脆弱的地方。
- 选 scDblFinder 做协变量的理由是工程性的：不需要 pK sweep（88 文库从 2.5 小时降到约 20 分钟）；原生连续分数（DoubletFinder 的 pANN 依赖 `nExp`，而 `nExp` 来自那个有歧义的预期率）。
- **MHC class II 是最糟的一类**：Mono_DC 里 MHC-II 配体的 provider RR = 2.00（非 MHC-II 为 1.53）。报告 MHC-II 相关组合时必须单列。
- **§5.4 第 2 步检查 #1 不通过**：配体阳性细胞 UMI 中位高 9–12%，21% 的单元超过 1.2 倍。这更像深度混杂而非 doublet 签名，所以 `CDR` 在模型里是承重的。
- 理由：这些数据多数是作者处理过的，剩下的 doublet 可能本来就不多。scDblFinder 在每个样本里标掉的比例差不多，不随细胞数变，更像是在标带混合表型的真细胞。
- 两个 caller 都按文库跑，不按患者对象跑。结果存成侧表，以细胞条形码为键，不改 `04_annotated` 的对象。
- 文库键：GSE185381 和 Chen2023 用 `Library` 列；其余数据集用 `orig.ident`。
- GSE185381 要先跨对象重组。把同一个文库的细胞从各个患者对象里取出来，拼成 47 个文库矩阵，跑完 caller 再把分数映射回细胞。重组时要包含该文库的全部细胞，包括健康供者和不合格样本的细胞，否则 caller 模拟 doublet 时会缺细胞类型。
- 混样文库的预期 doublet 率要按 demux 之后剩下的部分来设。跨供者的 doublet 已被去掉，剩下的只有供者内的：

  ```
  dbr_remaining = dbr_total * sum over donors d of p_d^2
                  # p_d = fraction of the library's cells that come from donor d
  ```

  5 个供者均分时是总比例的五分之一。scDblFinder 的 `dbr` 和 DoubletFinder 的预期数都按这个值给。不调的话，两个 caller 都会在混样文库里多标，口径 A 会多剔真细胞。
- 两种口径共用的设防：反应基因只取接收细胞自己表达的基因（§5.4 第 0 步）；第二阶段加每位患者的细胞数作协变量；“少数提供者”另过三项检查（§5.4 第 1 步）。

**2. 验证“数据已处理过”这个前提（不依赖任何 caller）**

在正常的 T 细胞和 B 细胞里，数同时检出两类标志的细胞。这两类标志在生物学上不会共存，也不受原始细胞跨系表达的影响。

```
# per dataset, pooled over libraries
obs   = cells among T and B cells with both CD3E and (CD79A or MS4A1) detected
exp   = sum over libraries of  D * 2 * f_T * f_B * d_T * d_B
        D        = expected number of doublets in the library, N * 0.008 * N / 1000
                   (rule of thumb: about 0.8% doublets per 1,000 cells recovered)
        f_T, f_B = fractions of T and B cells in the library
        d_T, d_B = detection rate of the T marker in T cells, of the B marker in B cells
ratio = obs / exp
```

- **判读只用非混样的样本**（`Pooled=FALSE`；GSE185381 有 11 个，其余数据集全部是）。混样文库里跨供者的 doublet 已被 demux 去掉，比值天然偏低。5 个供者的文库比值会在 0.2 左右，这是纯技术原因，不能当作“作者去过 doublet”的证据。
- 混样文库的比值单独报告，预期数乘上各供者占比的平方和，只作参考，不用于判断。
- 比值远小于 1：作者已经去过 doublet。
- 比值接近 1：当作没处理过，这个数据集要更看重口径 A 的结果。
- 预期数小于 5 的数据集标为“无法判断”。

**3. 细胞注释**：直接用对象 metadata 里的 `hierarchy_bin`、`bmm_fine`、`anno_malignant`。`high_error` 为真的细胞剔除。

**4. 信号活性打分（每个细胞）**

- 现在能做的是 Hallmark 基因集打分（UCell）。基因集在本地的 GMT 文件里（§0A）。
- PROGENy 的模型不在 OmnipathR 的缓存里，离线取不到。是否下载见 §15.2。
- CytoSig 的特征矩阵到位后再补一套，岭回归自己写。
- 两阶段检验本身不用信号打分。打分只用在“是否受益”一步和阳性对照的比对里。
- 打分基因与“适应度”基因不得重叠。

**5. 适应度代理（每个细胞）**：增殖评分（S 与 G2M 基因）、凋亡与 p53 通路评分、干性评分（项目已有的 LSC17、HSPC_core 等）。主读数见 §15。

### 5.4 步骤

**0. 细胞和基因的范围**

- “同一状态”用 `hierarchy_bin` 定义。主分析在 LMPP_GMP 和 Mono_DC 两个分箱里做，这是样本数够的两个。HSC_MPP 只在 GSE185381 够用，作补充。
- 细胞：分箱内全部通过投影质控的细胞，`anno_malignant` 作协变量（已冻结的细胞范围）。诊断期样本里这两个分箱以白血病细胞为主。只取 `anno_malignant` 为真的版本作敏感性分析。正常核型患者的恶性标签不可靠，所以主分析不依赖它。
- 反应基因的范围：只取接收细胞自己表达的基因。建议的定义是：在该类接收细胞里检出率不低于 5%，并且在任何其他细胞类型里的平均表达不超过接收细胞的 4 倍。混进来的细胞只会带来外来基因，这一步把它们挡在外面。
- 受体基因自己不算反应基因。

#### 主分析：同分箱（设想 C）

**1. 提供者结构（H-C1）**

- 每位患者、每个分箱、每个配体，算检出该配体的细胞比例和 Gini 系数。
- 检出的不均匀程度是否超过同等平均表达下的随机期望（负二项零模型）。
- 在 `bmm_fine` 的每个细分状态内部重复一次。只在某个细分状态里才有的不均匀，算作状态差别，不算分工。
- 回归掉细分状态、细胞周期、nUMI 之后，配体阳性细胞是否仍带有跨患者可重复的共表达程序。对照是表达水平匹配的随机基因。
- 三项“不是 doublet”的检查，因为“少数白血病细胞表达别的细胞的配体”正是 doublet 的样子：
  1. 配体阳性细胞的 UMI 总数不应明显偏高。
  2. 它们不应同时带上另一类细胞的整套标志基因。
  3. 它们的比例应高于预期的 doublet 比例，并且不随上样细胞数增加。

**2. 提供者的多寡**（每位患者 p、分箱 b、配体 L）

```
A[L,p,b] = mean expression of L over all cells of bin b in patient p
           (also report the fraction of L-positive cells)
```

**3. 接收细胞**：分箱 b 里没有检出 L 的细胞。配体阳性的细胞排除在外，这样同一个细胞不会既算提供者又算受益者。

**4. 接收细胞的反应（第一阶段，每位患者内部）**

用线性模型，不用 MAST。同一位患者、同一个分箱里，所有受体共用一套协变量，只有受体指示列不同，所以一次矩阵运算就能得到全部受体、全部基因的系数。

```
# patient p, bin b, receivers = L-negative cells; n cells, k covariate columns
Z      = [1, CDR, bmm_fine, phase, malignant status, (doublet scores in arm B)]
Y_res  = Y - Z (Z'Z)^-1 Z' Y                  # cells x genes, log-normalized
r_R    = Rpos - Z (Z'Z)^-1 Z' Rpos            # one column per receptor
beta[R,g]   = (r_R' Y_res[,g]) / (r_R' r_R)
sigma2[R,g] = (sum(Y_res[,g]^2) - beta[R,g]^2 * (r_R' r_R)) / (n - k - 1)
se[R,g]     = sqrt(sigma2[R,g] / (r_R' r_R))
```

- `Rpos` 是受体是否检出，`CDR` 是细胞检出基因的比例。
- 接收细胞集合随配体而变（要排除该配体的阳性细胞），所以同一个受体对不同配体要分别算。配体阳性细胞很少时，可以先用全部细胞算一遍当近似，再对排名靠前的组合精确重算。
- 这一步只说明受体阳性和阴性细胞不同，还不能说是配体造成的。
- 显著性不靠这一步的 P 值，而是来自第二阶段在患者之间做的置换。
- 全量用 MAST 算不动。等有了排名靠前的结果，再考虑装 MAST 只对它们做交叉核对。

**5. 跨患者交互（第二阶段，单位是患者）**

```
beta[g,p] ~ A[L,p,b] + A_other[L,p] + covariates(p)     # weights 1/se^2; within study
-> b[g]; permutation p-value by shuffling A[L,·,b] across patients
A_other[L,p]  : availability of the same ligand from the best other compartment
covariates(p) : number of cells, prop7, blast%, genotype where available
```

- `b[g]` 显著的基因，就是“提供者多的患者里才出现的受体依赖反应”，称为配体效应基因。每个（配体、受体、分箱）组合的统计量是配体效应基因的个数，和置换零分布比。
- `A_other` 把别的区室供给的同一种配体放进模型。同分箱的效应如果在加入它之后消失，说明它只是跨区室信号的影子。
- 参考阈值（来自 ContactTracing 原文）：交互效应基因不少于 10 个（FDR < 0.25）。

**6. 假配体对照**（每个要报告的组合都要过）

同一状态的细胞之间，最大的威胁是状态本身的漂移：某位患者这个分箱整体偏向某种状态，配体表达和受体阳性细胞的差别会一起变。所以真配体的效应要超过同分箱里表达水平相近的假配体（第 95 百分位）。假配体的取法同 §5.6 第 4 条，只是在同一个分箱里取。

**7. 是否受益（H-C3）**：配体效应基因里有没有增殖、存活相关程序；`fitness ~ Rpos × A[L,p,b]` 的交互是否为正。

**8. 发现与重复**

- 发现在 GSE185381 和 GSE239721 里各自完成。
- 另外三个研究只检验发现阶段给出的组合，看方向是否一致，再做随机效应 meta 分析。8 位患者时，秩相关的绝对值要到 0.74 左右才显著，这些研究单独做发现没有检验力。

#### 对照和背景：跨区室

**9.** 跨区室的组合用同一套检验跑，发送区室和接收类型不同，配体可得性取发送区室内的平均表达（每位患者该类细胞不少于 30 个）。阳性对照（GATE_W1.1）属于这一类。结果放补充材料，用途有两个：说明方法能找回已知的反应；给第 5 步提供 `A_other`。

#### 可选

**10.** 有模块 G 的结果时，给提供者和受益者所在的细胞群标上突变细胞比例（§5A）。模块 G 目前暂停。

### 5.5 对照与反证

- **doublet 两种口径**：见 §5.3。
- **假配体**：见第 6 步，每个要报告的组合都要过。
- **假配对**：把配体和受体的配对关系在表达水平相近的基因间打乱，重跑第二阶段。真实配对的显著数必须明显多于假配对。
- **跨区室供给**：第二阶段加入 `A_other` 后，同分箱的效应不应消失。
- **混杂识别**：受体阳性与阴性细胞的差异如果在所有患者里都一样、和配体多寡无关，那是受体标记了某个亚群，不是配体效应。
- **患者间的混杂**：配体多的患者可能在别的方面也不同。协变量见第二阶段，结论不应在加入协变量后消失。
- **污染**：配体效应基因如果主要是发送细胞的标志基因，按环境 RNA 或 doublet 处理，不算反应。
- **方向**：混入的细胞只会让基因看起来上调。配体效应基因里如果有一批下调的基因，这部分不可能来自污染。
- **深度**：受体阳性细胞通常 UMI 更多。`CDR` 必须在模型里，并按 nUMI 分层重复一次。

## 5A. 可选模块 G：基因型注释（NPM1 读数）

### G.1 定位

- 不在主线上。WP1–WP3 不依赖它。
- 两个用途。一是给正常核型的患者补一个不依赖 CNV 的恶性证据，这类患者里 inferCNV 和 Numbat 没有可抓的信号。二是 WP1 出结果后，回答“提供者和受益者所在的细胞群是不是以突变细胞为主”。
- 什么时候做：WP1 通过门槛之后，并且能拿到原始 reads。
- **现状：暂停投入（2026-10-02）。** 它不属于四个原始设想。已有的实测记录保留，主线需要时再启用。

### G.2 第一次实测（20 bp k-mer；已被 G.2b 取代，留作记录）

样本：GSE227903，患者 40389，10x 3′ v3.1，临床标注 NPM1 阳性。这是复发期样本，数字只作校准用。

| 指标 | 数字 |
|---|---|
| 盖住热点的 reads | 6,294 |
| 可判读 UMI | 2,217，无冲突 |
| 有可判读 UMI 的细胞 | 910 / 5,471 = 16.6% |
| T/NK 细胞里的突变 UMI | 0 / 527（486 个细胞） |
| 只有 1 个可判读 UMI 的细胞 | 约 75% |

| 层级分箱 | 突变 | 野生型 | 未定 |
|---|---|---|---|
| Mono_DC | 69 | 11 | 72 |
| LMPP_GMP | 16 | 76 | 79 |
| HSC_MPP | 7 | 25 | 19 |

怎么读这些数字：

1. **3′ 文库可用**。覆盖 16.6%，约为 5′ 文库已发表数字（48%、57%）的三分之一。
2. **分类器干净**。527 个 T/NK 的 UMI 里没有一个突变。报告时写上限：0/527 对应的 95% 上限约 0.6%，不要写成 0。
3. **同一分箱里两种基因型凑不齐**。突变多的分箱野生型少，反过来也一样。这是白血病细胞占据特定状态造成的，不是测量问题。诊断期样本会不会好一些，目前没有数据，不作为前提。
4. **逐细胞判定野生型的把握很低**。四分之三的细胞只有 1 个可判读 UMI。
5. 数量最多的突变细胞在 Mono_DC。干祖细胞层级里，突变细胞主要落在 LMPP_GMP，这一点与 Chen 2023 的报道一致。

### G.2b 修正后的实测（76 bp k-mer）

- 20 bp 的野生型 k-mer 在全基因组出现 18 处，其中 6 处是 NPM1 的加工假基因（P14、P22、P28、P36、P39、P42）。突变 k-mer 出现 0 处。所以假基因只会造出假的“野生型”。
- 修正后的参数：左侧 16 bp（从最后一个外显子的起点到插入点），右侧 60 bp，两个等位强制等长，都是 76 bp。这时野生型 k-mer 在基因组里唯一，突变 k-mer 为 0。再加“只取唯一比对的 reads”这个过滤，一个数都不变。
- 两个等位等长，保证突变和野生型 reads 被读到的机会相同。

| 指标 | 20 bp k-mer | 76 bp k-mer |
|---|---|---|
| 有可判读 UMI 的细胞 | 16.6% | 5.6% |
| 可判读 UMI 总数 | 2,217 | 约 330 |
| 突变 UMI 的比例 | 0.124 | 0.120 |
| T/NK 细胞里的突变 UMI | 0 / 527 | 0 / 170 |

- 主结论没变：突变 UMI 的比例只从 0.124 变到 0.120。
- 按细胞群估计的突变细胞比例更符合预期：LMPP_GMP 最高（1.00），T_NK 为 0。
- G.2 里那张逐细胞判定的分箱表是旧参数的结果，不再使用。
- 代价是可判读 UMI 少了很多，细胞群层面的估计会变粗。

### G.3 因此改变的做法

- 不再要求“同一分箱内两种基因型各 ≥30 个细胞”。v1 的 GATE_W1.1 作废。
- **改为按细胞群汇总 UMI**，不依赖逐细胞判定：

  ```
  f_S  = mutant UMIs / informative UMIs, pooled over all cells in set S
  pi_S = (f_S - eps) / (theta - eps), clipped to [0, 1]   # mutant-cell fraction in S
  ```

  `S` 可以是一个层级分箱，也可以是 WP1 定义的细胞群。置信区间用对细胞的 bootstrap。
- **用法 1**：每位患者每个分箱的 `pi`，与 CNV 共识标签对照，给正常核型患者补恶性证据。
- **用法 2**：同一分箱内，比较配体阳性细胞与配体阴性细胞的 `f`。每位患者得到一个差值，跨患者检验。受体阳性且有反应的细胞同理。
- **探索项，不进主结论**：把逐细胞后验 `P_mut` 当连续协变量，`score_s(c) ~ P_mut(c) + covariates`，未定的细胞也参与。它假设同一分箱里两类细胞暴露相同。

### G.4 校准

1. **theta**。污染率实际接近 0，所以带突变 UMI 的细胞可以认为就是突变细胞。在这些细胞里取可判读 UMI ≥3 的，估计突变 UMI 的比例。要校正“至少有一条突变 UMI 才被选中”造成的偏高：`E[m | m >= 1, n] = n * theta / (1 - (1 - theta)^n)`。修正后的突变细胞比例已经用到了 theta，估计值请补记到 `GATES.md`。
2. **k-mer 的唯一性**：已完成，通过（GATE_G.4.2）。
3. **右侧长度扫描**（建议）。右侧 60 bp 不一定是唯一性所需的最短长度。把右侧长度从 20 扫到 60，取刚好让野生型 k-mer 唯一的那个值，可以追回一部分覆盖率。两个等位仍要等长。

## 6. WP2 治疗后仍在的多细胞程序（设想 A）

### 6.1 假设

- **H-W2a**：扣掉细胞比例之后，AML 骨髓里存在跨细胞类型一起变的表达程序，并且与基因型或预后有关。
- **H-W2b**：缓解期或 MRD 期的骨髓，这些程序的得分仍高于健康供者。
- **H-W2c**：同一患者诊断期和缓解期的程序得分相关，缓解期得分高的患者更容易复发。

### 6.2 数据要求

| 用途 | 要求 | 候选 |
|---|---|---|
| 发现 | 多患者、未分选骨髓、诊断期；每个研究内部患者数尽量多 | GSE185381、GSE239721、GSE289435、GSE227903、GSE116256；AML scAtlas 里追溯到的原研究 |

| 结局 | 复发或持续缓解的标注 | Mumme 2023 |
| 配对确认 | 诊断 → 复发 11 对 | GSE227903（9 对）、GSE201966（2 对） |
| 健康参照 | 健康骨髓 | 各 AML 研究内的健康供者、E-MTAB-11536 |

儿童和成人分开分析，骨髓和外周血分开分析。

### 6.3 步骤

1. **环境 RNA（数据内估计，不需要未过滤矩阵）**。拿 T/NK 细胞当探针，和估计 NPM1 污染率是同一个思路：

   ```
   # per sample s
   G_never = genes with near-zero detection in T/NK cells of healthy donors
             (fixed reference list, built once from the healthy samples)
   G_imp   = the 50 most highly expressed genes of sample s that are in G_never
   num(c)  = UMIs of G_imp in T/NK cell c / total UMIs of c
   den     = UMIs of G_imp over all cells of s / total UMIs of s
   rho_s   = median over T/NK cells of num(c) / den        # contamination fraction
   ambient profile of s ~ pseudobulk of all cells of s, normalized to sum 1
   ```

   - 每个样本至少 50 个 T/NK 细胞才估计，否则记为缺失。
   - 血红蛋白基因不进这个比值。它们的环境来源是裂解掉的红细胞，这些红细胞不在细胞集合里，会让比值失真。血红蛋白基因在 T/NK 细胞里的水平单独报告。
   - 黑名单取每个样本环境谱里排名靠前的基因。原始细胞多的样本，blast 的 RNA 会进入所有其他细胞，正好伪装成“多类细胞一起变”。
   - 这个估计假设环境谱接近全样本的 pseudobulk。容易裂解的细胞贡献会更多，所以它是近似值，用来排序和设防，不用来精确校正。
2. **分组**：恶性细胞按层级分箱；非恶性细胞按类型。每个样本每组不少于 30 个细胞才计入，某组要在七成以上样本里存在才保留（两个数都是建议值）。
3. **状态控制的 pseudobulk**：每个样本、每个组各自汇总成一个表达谱。已有的 `12_pseudobulk_de` 可以复用。这样“某种细胞变多”和“同一种细胞内部表达变了”被分开。这一步借自 GBM CARE 联盟的做法。
4. **研究内部发现程序**：供者 × 基因 × 细胞组的张量做 Tucker 分解，自己写（scITD 没装，不为此安装；思路照 scITD）。备选是 DIALOGUE 的做法（跨细胞类型的稀疏典型相关加多层模型）。因子个数用“对供者再抽样后的稳定性”来定。
5. **去混杂**：每个因子与 blast%、污染比例、细胞比例、nUMI、性别、年龄逐一检验。主要被 blast% 或污染比例解释的因子标记出来，不进入后续结论。因子的高载荷基因与环境黑名单的重叠不应超过随机水平。
6. **跨研究重复**：把一个研究里得到的载荷投到另一个研究，算得分，再看两边的载荷相关性和与表型的关联方向是否一致。
7. **是否超出细胞比例**：嵌套模型比较，`表型 ~ prop7` 对比 `表型 ~ prop7 + 程序得分`，按患者做交叉验证和 bootstrap。
8. **纵向**：
   - 缓解期或 MRD 期样本对比健康供者（单位是患者）。
   - 同一患者诊断期与缓解期得分的相关。
   - 11 对诊断 → 复发：只检验预先固定的模块，不超过 4 个。
   - Mumme 数据里，诱导结束时的得分对比复发与持续缓解两组。
9. **解释层**：某个程序里，A 类细胞的配体与 B 类细胞的程序部分相关时，回到 WP1 的两阶段检验去确认受体依赖的反应。
10. **bulk 外推**：取程序里各细胞类型特异的基因组成签名，在 BeatAML、TCGA-LAML 里打分，看预后。bulk 分不开细胞类型，这一步只当旁证。

### 6.4 关于 11 对的检验力

11 对做符号翻转置换，共 2^11 = 2048 种排列。按最朴素的符号检验：11 对全部同向，双侧 p ≈ 0.001；10 对同向，p ≈ 0.012。做 Bonferroni 校正并容忍一位患者不一致，模块最多 4 个。模块必须在看这 11 对之前固定下来。

### 6.5 对照与反证

- 程序效应在控制 blast%、细胞比例、取样来源、处理流程之后消失，就不能说发现了独立的生态机制。
- 只有两个时间点，只能说“仍然异常”或“发生了转变”，不能说吸引子、迟滞、稳定反馈。
- “持续存在”不靠“诊断和缓解没有差别”来证明，那等于证明没变，11 对做不到。

### 6.6 通过门槛（建议值，待冻结）

| 门槛 | 指标 | 建议值 |
|---|---|---|
| GATE_W2.1 环境 RNA | 因子得分与数据内估计的污染比例 `rho_s` 的相关；高载荷基因与环境黑名单的重叠 | 校正后 \|ρ\| < 0.3；重叠不超过随机期望 |

### 6.7 已有工作与新意

- AML 里已有按细胞状态“共存模式”定义生态系统的工作（ACE，Brief Bioinform 2025，6 套数据、68 例患者），并在 bulk 队列里验证了预后意义。所以只讲“生态型”或“细胞共现”不新。
- 多发性骨髓瘤里也有按细胞亚群比例的 NMF 定义 TME 生态型的工作。

## 7. WP3 代偿与共享瓶颈（设想 B）

WP2 给出“缓解期仍异常的程序”之后才启动。对象固定为这个程序，不换成别的程序。

### 7.1 假设

治疗后仍在的那个程序，由蛋白信号和代谢物信号共同维持。两类输入可以互相替代：阻断其中一个，另一个可以顶上。它们在细胞内汇到同一批转录因子上，这批因子是共享瓶颈。

### 7.2 做法

1. **候选输入名单**。只当名单用，不用这些工具的打分。
   - 蛋白一侧：配受体数据库里的受体。WP1 里显著的组合优先。
   - 代谢物一侧：代谢物的 sensor 和转运体，取自 MEBOCOST 的数据库。
   - 汇聚关系：受体到转录因子到靶基因，照 SigXTalk 的思路。
2. **样本内部的冗余检验**（每位患者、每类接收细胞）：

   ```
   program(c) ~ R1pos(c) + S2pos(c) + R1pos(c):S2pos(c) + CDR(c) + bmm_fine(c)
   # R1 = a protein receptor; S2 = a metabolite sensor or transporter
   # program = score of the WP2 program genes that belong to this cell type
   ```

   两个主效应都为正、交互项为负，说明两类输入对同一程序有饱和或互相替代的关系。每位患者得到一个交互估计，跨患者检验。
3. **只在 R1 阴性的细胞里看 S2**：没有 R1 的细胞里，S2 的表达是否仍然伴随同一程序。这是代偿最直接的读法。反过来也做一次。
4. **共享瓶颈**：用转录因子活性打分，找同时与 R1、S2 的反应相关的因子。
5. **程序打分的基因与 R1、S2 及其已知下游不得重叠**，否则是循环使用同一组基因。
6. **在哪些样本上做**：诊断期样本细胞多，做主检验。治疗后的样本（MRD、缓解期）很少，只看方向是否一致。

### 7.3 反证

- 关联如果只来自总体应激、同一患者的 blast 数或批次，拒绝机制解释。
- 代谢物是用酶和 sensor 的 mRNA 推出来的，只能叫候选，不能当作浓度或流量。
- 样本里基本没有基质细胞，来自基质的输入看不到。
- sensor 和转运体多数是组成型表达，“阴性”可能只是没测到。和 WP1 的受体是同一个问题，结果要对照 §5.6 第 9 条的诊断来读。

### 7.4 验证

这一包最适合交给实验收尾：单独阻断蛋白一侧、单独阻断代谢物一侧、同时阻断，比较接收细胞的程序和存活。代谢物一侧的候选优先留给实验。

## 9. 暂缓的方向及原因

| 方向 | 原因 | 什么情况下重开 |
|---|---|---|
| 跨样本通讯张量（MEBOCOST、SigXTalk 打分拼成张量再分解；Tensor-cell2cell） | 分数是“发送细胞群均值 × 接收细胞群均值”，和旧主线同一结构，已知不超过细胞比例基线 | 不重开；问题本身改到 WP3 |
| 设想 D：CellOT 反事实预测当主线 | AML 没有合格的公开扰动训练数据；没有“阻断通讯”的数据。2026-10-02 确认搁置，只留作 WP4 的验证模块 | 自己产生扰动数据之后 |
| 患者前后的“治疗效应”推断（LEMUR、CINEMA-OT、MrVI） | 患者前后是观察数据，药物作用、克隆选择、造血恢复混在一起，不能叫治疗效应 | 可作探索，统一叫“配对变化”；LEMUR 的设计写成 `~ patient + timepoint` |
| 把时间点当 ContactTracing 的条件 | 化疗直接改变接收细胞；原文的条件是肿瘤细胞内部的遗传操作，不直接作用于免疫细胞 | 只作探索，不进主结论 |
| TIGON 增长率 | 需要每位患者至少 3 个时间点，且细胞数能代表真实数量；现有数据不满足 | 有未分选的密集时间点数据之后 |
| 以细胞共现或生态型为主线（CoVarNet 式） | AML 已有同类工作（ACE）；比例受 blast 负荷和富集流程影响 | 只在 WP2 里作为基线对照 |
| scComm、scHyper 的打分 | scComm 把得分最高 5% 的细胞类型对当作真实事件来训练，标签来自自己的打分 | 不采用打分；“通讯角色”这个问题已并入 WP1 |
| 图神经网络、单细胞大模型（PINNACLE、Geneformer 等） | 2025 年 Nature Methods 的评测显示深度学习预测扰动效应未超过线性基线；AML 缺少可监督的标签 | 主线成立后再考虑 |
| 同一分箱内突变对野生型的逐细胞比较（v1 的 WP1a 主检验） | 实测显示两种基因型很少落在同一分箱；多数细胞只有 1 个可判读 UMI | 改为细胞群层面的汇总（模块 G）；有 5′ 文库或靶向富集的数据时再议 |
| 把治疗当工具变量（scIVCCC） | 化疗直接作用于多类接收细胞，排除限制不成立 | 不重开 |

## 12. 统计与复现规则

- 外层按患者或按研究留出。同一患者的所有时间点放在同一分区。不能先用全部数据学出模块，再把结局预测称为独立验证。
- 每位患者、每个细胞类型做 pseudobulk 或低维汇总后再比较。不确定性用患者级 bootstrap 和配对置换来估计。
- 每个研究内部先估计效应，再比较或汇总。不同方案、年龄、取样时间和材料的样本不直接混成一个队列。
- 打分用的基因和被检验的基因尽量不重叠。每个结论配上基因集匹配、组成匹配、标签置换和简单方法基线。
- 没有原始采样比例时，不把富集样本的细胞频率当成真实骨髓丰度。
- 同一研究衍生出的图谱文件、GEO 文件、CELLxGENE 文件，同一位患者只算一次。
- 门槛和主读数在看结果之前写进 config 并提交，改动要留记录。
- 每个含随机性的步骤固定随机种子，种子取 `config_paths.R` 里的全局 `SEED`。
- doublet 两种口径下都成立的结果才进主结论。正文数字用“不硬剔除”口径，并集口径放补充材料。
- 注册过的阈值不事后修改。新增的阈值要写明是在看过哪些数字之后定的。“重复研究 ≥8 位患者”这一条，是在看过各研究的组合数、没看过任何检验结果之后定的。
- 发现和重复用不同的研究。重复阶段只检验发现阶段给出的组合。
- 对已冻结门槛的修订，只能发生在相关结果出现之前，并写明依据。GATE_W1.1 在 T3c 之前修订过一次，依据只有检出统计。

## 13. 结论的边界

可以说的：

- 少数细胞贡献了某个配体的大部分表达，并且这一点在多位患者里重复出现。
- 某个配体多的患者里，带对应受体的细胞出现了特定的表达变化。
- 某个多细胞程序在缓解期仍高于健康水平，并与结局相关。

不能说的：

- RNA 推出的通讯不等于物理邻近、配体结合、代谢物流量。
- 患者间配体的多寡不是随机分配的。第二阶段的结果是关联，要靠协变量、假配对和实验来收紧。
- 模块 G 的探索项假设同一分箱里的突变和野生型细胞“暴露相同”。骨髓里如果两类细胞位置不同，这个假设会被破坏。
- 患者前后的差别不是治疗的因果效应。
- 删除模型里的一条边导致输出变化，只说明模型敏感，不说明真实干预的结果。
- 只有表达数据，不能得出“阻断某条通讯可以避免复发”。
- 临床报告的 NPM1 或 FLT3 状态是患者层面的标签，不是细胞层面的亚克隆标签。

最低可写的结果由三类证据定义：跨研究稳定；患者内有相符的纵向变化；独立的扰动数据或实验支持预测方向。缺第三类时，结论限定为可重复的关联和候选机制。

| 热点 | chr5:171,410,540–171,410,543 |

B 型、D 型和其他 4 bp 插入的写法没有在本项目数据里核对过，用到时再查。

### A.2 读数流程（BAM 版本，已跑通）

1. 用 pysam 取热点上下各约 100 bp 范围内的 reads，包括被软剪切的 reads。插入位点靠近 read 末端时，比对软件常把它剪掉，所以不能只看 CIGAR。
2. 对每条 read 的原始序列，找等位特异的 k-mer（现用 76 bp，见 A.1）。read 要完整盖住这 76 bp 才算有信息。分为突变、野生型、无信息三类。两个等位等长，被读到的机会相同。
3. 同一个 `CB` 加 `UB` 下的 reads 合并成一个 UMI；出现冲突的 UMI 丢弃。76 bp 参数下患者 40389 约有 330 个可判读 UMI（20 bp 时是 2,217 个）。加“只取唯一比对的 reads”这个过滤，结果不变。
4. 输出每个细胞的 `n_mut_umi`、`n_wt_umi`。

### A.3 读数流程（FASTQ 版本，待实现）

1. 在 cDNA 那一端的 read 里直接找 A.2 第 2 步的 k-mer 及其反向互补。
2. 从配对的另一端 read 取细胞条形码和 UMI，条形码按白名单纠错，只保留已通过 QC 的细胞。
3. 其余同 A.2。
4. k-mer 的唯一性已确认（A.1）。没有比对这一层把关，FASTQ 版本只能用 76 bp 的 k-mer，不能用短的。在患者 40389 上与 BAM 版本对账。

### A.4 细胞群层面的估计（主用法）

```
f_S  = mutant UMIs / informative UMIs, pooled over all cells in set S
pi_S = (f_S - eps) / (theta - eps), clipped to [0, 1]
```

- `eps`：野生型细胞里出现突变 UMI 的比例，用 T、NK、B 细胞估计。76 bp 参数下实测 0/170，单侧 95% 上限 1.75%。
- `theta`：突变细胞里突变 UMI 的期望比例。杂合突变且两个等位表达相近时约为 0.5，要用数据估计（§G.4）。
- 这种估计不需要判断单个细胞是不是野生型，所以不受“多数细胞只有 1 个 UMI”的限制。
- 注意 `pi_S` 是按 UMI 加权的比例。突变细胞和野生型细胞每个细胞的可判读 UMI 数如果不同，它会偏。核对办法：每个细胞随机只取 1 条 UMI 再算一遍，两个版本应接近。

### A.5 逐细胞后验（只用于探索）

记 `n = n_mut_umi + n_wt_umi`，`m = n_mut_umi`，`pi_b` 为分箱 b 里突变细胞的先验比例（用 EM 估计）。

```
P(mut | m, n) = pi_b * Binom(m; n, theta)
                / ( pi_b * Binom(m; n, theta) + (1 - pi_b) * Binom(m; n, eps) )
```

取 `theta = 0.5`、`eps = 0.01`，细胞里一条突变 UMI 都没有时：

| 分箱里突变细胞的先验比例 | 野生型 UMI 数 | 仍是突变细胞的后验概率 |
|---|---|---|
| 0.9 | 3 | 0.54 |
| 0.9 | 7 | 0.07 |
| 0.5 | 3 | 0.11 |
| 0.5 | 4 | 0.06 |

在突变细胞占多数的分箱里，要 7 条左右的野生型 UMI 才能判为野生型。实测四分之三的细胞只有 1 条，所以逐细胞的野生型判定在这类分箱里基本做不到。这就是主用法改成 A.4 的原因。

### A.6 核对项

- 健康供者样本里突变 UMI 应接近 0。
- T、NK、B 细胞里的突变 UMI 比例逐样本报告，写上限。
- `theta` 的估计值逐样本报告。
- van Galen 数据有独立的靶向基因分型，可用来核对一致性。
- 5′ 文库的覆盖率应明显高于 3′ 文库，可对照 Petti 2019 的量级。
